🏅 Olympic Data Analysis using Power BI
📌 Project Overview
        The Olympic Games generate a vast amount of data related to athletes, countries, sports, and medals across different years.
        This project focuses on analyzing Olympic historical data using Power BI to create meaningful and interactive visualizations.
        The dataset was collected from Kaggle, cleaned and preprocessed using Microsoft Excel, and then loaded into Power BI for analysis and dashboard creation.

🎯 Objectives
       Analyze Olympic medal distribution across countries
       Identify top-performing nations and sports
       Understand medal trends over different Olympic years
       Create interactive dashboards for easy data exploration
       Demonstrate real-world data cleaning and visualization skills


🧰 Tools & Technologies Used
      Power BI – Data modeling and interactive visualization
      Microsoft Excel – Data cleaning and preprocessing
      Kaggle – Dataset source
      CSV / Excel files – Data storage format


📊 Data Collection
      Dataset downloaded from Kaggle
      Data provided in CSV / Excel format
      Contains historical Olympic data including:
      Athlete details
      Country / NOC
      Sport and event
      Year
      Medal information


🧹 Data Cleaning (Excel)
      Data preprocessing was performed using Microsoft Excel, including:
      Removing duplicate records
      Handling missing and null values
      Standardizing country and sport names
      Filtering unnecessary columns
      Formatting data for Power BI compatibility
      After cleaning, the finalized dataset was loaded into Power BI for analysis.


📈 Power BI Dashboard Features
      Country-wise medal count analysis
      Year-wise medal trends
      Sport-wise performance comparison
      Interactive slicers for country, year, and sport
      KPI cards showing total medals and top countries
