# 🏅 Olympic Data Analysis

## 📌 Project Overview

Olympic Data Analysis is an interactive data analytics project developed using **Power BI** to explore and analyze Olympic Games data. The project provides insights into medal distribution, country-wise performance, athlete participation, and medal trends across different Olympic Games.

The dashboard transforms raw Olympic data into meaningful visualizations that help users understand historical performance and identify trends.

## 🎯 Objectives

* Analyze Olympic medal distribution across countries.
* Compare country-wise performance in different Olympic Games.
* Identify trends in medal achievements over the years.
* Analyze athlete participation and performance.
* Create an interactive dashboard for easy data exploration.
* Present meaningful insights through data visualization.

## 🛠️ Technologies Used

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculations and measures
* **Excel / CSV** – Dataset and data preparation

## 📊 Dashboard Features

The Power BI dashboard includes:

* 🌍 Country-wise medal analysis
* 🥇 Gold, Silver, and Bronze medal analysis
* 📈 Medal trends across Olympic years
* 🏃 Athlete participation analysis
* 🏆 Top-performing countries
* 🎯 Interactive filters and slicers
* 📊 Dynamic charts and visualizations

## 🔍 Key Insights

The analysis helps identify:

* Countries with the highest number of Olympic medals.
* Distribution of Gold, Silver, and Bronze medals.
* Changes in Olympic performance over different years.
* Countries and athletes with notable performances.
* Overall trends in Olympic participation and achievements.

1. Clone or download this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open `Olympic_Data_Analysis.pbix`.
4. Explore the dashboard using the available filters and slicers.
5. Interact with the visualizations to analyze Olympic performance.
